# 巫碗子简介

巫碗子(**Fuwanko**)是我(**WizardsBowl**/**碗里巫云**)的另一个博客。

## 主站和副站

本站(巫碗子)是本人博客的副站，主站为[巫师之碗](https://www.wizardsbowl.com)。

这一开始是我正式搭建个人博客之前，用于尝试建站的测试性网站。

主站搭建好之后就顺便确立了主副站关系。

## 副站是干啥的

首先可能会把建站的历程和方法记录下来，之后可能会记录一些解决其他问题的经历。

目前的打算是，主站记录一些比较成体系的东西，而比较零散的就会放在副站。

## 关于副站的名称

一开始我打算把主站叫做巫师之碗，副站就叫巫碗（呜哇！）。

那“子”是哪儿来的？

这个问题恐怕你得问自动补全。
