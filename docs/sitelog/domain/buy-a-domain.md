# 购买域名

本页面记录了我购买域名的历程。

## 动机

其实我早些年就有买域名搭建个人网站的想法，主要还是抱着试一试、玩一玩的心态，想尝试一下。@@喜欢折腾@@

就和我最开始学编程一样，纯粹出于一时兴起，后来有些就变成了兴趣爱好。

## 实际购买

某天我终于决定付诸行动时，我搜索“购买域名”，Bing给出的第一条结果是阿里云~~的搜索引擎广告~~，想着阿里也是国内大厂，就点进去开始选域名。

最开始买了`.cn`域名，也是有点文化认同在里面的。然而购买后我才想起来去网上搜索购买域名的经验，发现国内对`.cn`域名的评价似乎不太好，于是乎又买了`.com`域名。

反正现在的结果就是主站的`.cn`域名会跳转到`.com`域名。（然而此站是副站）

后来又想想，地区的顶级域名有一些特殊要求其实也正常，参见[什么是域名？ - 学习 Web 开发 | MDN](https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Howto/Web_mechanics/What_is_a_domain_name)。

> 顶级域名可以告诉用户域名所提供的服务的一般目的。最通用的顶级域名（`.com`、`.org`、`.net`）不需要 Web 服务满足特定的标准，但一些顶级域名则执行更严格的政策（因此它们的目的更加明确）。比如：
> - 地区的顶级域名，如`.us`、`.fr`或`.sh`，可以要求必须提供给定语言的服务或者托管在指定国家——它们应该表示特定语言或国家的资源。
> - 包含`.gov`的顶级域名只能被政府部门使用。
> - `.edu`顶级域名只能为教育或学术机构使用。
